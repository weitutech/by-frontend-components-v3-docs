特性概览 ​

  • 🚀 Vue 3 驱动 - 基于 Vue 3 Composition API 构建

  • 🎨 现代化设计 - 采用现代化的设计语言
  • ⚡ 高性能 - 基于 Vite 构建，支持 Tree Shaking
  • 🔧 易于使用 - 提供详细的文档和示例

开始使用 ​

bash
# 安装组件库
npm install @weitutech/by-components-v3

# 在项目中引入
import ByComponentsV3 from '@weitutech/by-components-v3'
import 'by-components-v3/dist/style.css'

文档部署指南 ​

本文档说明如何将 ByComponents V3 组件库文档部署到 GitHub Pages。

部署方式 ​

方式一：手动部署（推荐用于测试） ​

  1. 构建文档

    bash
    npm run docs:build

  2. 执行部署脚本

    bash
    npm run docs:deploy
# 或者直接执行
bash deploy.sh

方式二：自动部署（推荐用于生产） ​

使用 GitHub Actions 实现自动部署，当推送代码到主分支时自动构建和部署文档。

GitHub Pages 配置 ​

1. 仓库设置 ​

  1. 进入 GitHub 仓库设置页面
  2. 找到 "Pages" 选项
  3. 在 "Source" 部分选择 "Deploy from a branch"
  4. 选择 gh-pages 分支
  5. 点击 "Save"

2. 分支说明 ​

  • 不需要手动创建 gh-pages 分支
  • 部署脚本会自动创建该分支
  • GitHub Actions 也会自动管理该分支

3. 访问地址 ​

部署成功后，文档将在以下地址访问：

https://weitutech.github.io/by-frontend-components-v3-docs

部署流程详解 ​

手动部署流程 ​

  1. 构建阶段

    • 执行 npm run docs:build
    • 生成静态文件到 docs/.vuepress/dist

  2. 部署阶段

    • 进入构建目录
    • 初始化 Git 仓库
    • 创建 gh-pages 分支
    • 推送代码到远程仓库

自动部署流程 ​

  1. 触发条件

    • 推送到 main 或 master 分支
    • 修改了 docs/、packages/ 或 package.json 文件

  2. 执行步骤

    • 检出代码
    • 安装依赖
    • 构建文档
    • 部署到 GitHub Pages

常见问题 ​

Q: 部署后页面显示 404？ ​

A: 检查以下几点：

  • 确认 GitHub Pages 已启用
  • 确认 gh-pages 分支存在
  • 等待几分钟让 GitHub 完成部署

Q: 样式文件加载失败？ ​

A: 检查 VuePress 配置中的 base 选项：

js
// docs/.vuepress/config.ts
export default defineUserConfig({
  base: '/by-frontend-components-v3-docs/', // 确保与仓库名一致
  // ... 其他配置
})

Q: 如何自定义域名？ ​

A: 在 deploy.sh 中取消注释并修改：

bash
echo 'your-domain.com' > CNAME

本地测试 ​

在部署前，可以在本地测试文档：

bash
# 启动开发服务器
npm run docs:dev

# 构建并预览
npm run docs:build
npm run preview

监控部署状态 ​

  1. GitHub Actions

    • 在仓库的 "Actions" 标签页查看部署状态
    • 查看构建日志和错误信息

  2. GitHub Pages

    • 在仓库设置的 "Pages" 页面查看部署状态
    • 查看访问统计和错误信息
